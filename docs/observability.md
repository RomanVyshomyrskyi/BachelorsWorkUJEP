# Observability Layer

Structured metrics collection and Prometheus integration for AutomationMCPSuperset.

## Architecture

```
MCP Tools → MetricsCollector → JSON logs + Prometheus metrics
                                       ↓
                                  /metrics endpoint
                                       ↓
                                Prometheus (pull)
                                       ↓
                                  Grafana (3 dashboards)
```

## Metrics

### Counters

| Metric | Labels | Description |
|--------|--------|-------------|
| `tool_calls_total` | `tool`, `status` | All MCP tool executions |
| `resources_created_total` | `resource_type` | Datasets, charts, dashboards, virtual datasets |
| `transfers_total` | `status` | Dashboard transfers (success/failed/partial) |
| `transfers_items_total` | `status`, `item_type` | Per-item transfer stats |
| `queries_executed_total` | `source` | SQL Lab, data queries, chart data |
| `charts_generated_total` | `chart_type` | Bar, line, scatter, pie, explore |
| `dashboards_generated_total` | `layout_type` | Simple, robust, full dashboard |
| `api_requests_total` | `method`, `endpoint`, `status_code` | HTTP calls through api_client |
| `db_queries_total` | `db_type`, `status` | Direct DB queries (DBAnalysis) |

### Histograms

| Metric | Labels | Description |
|--------|--------|-------------|
| `tool_duration_seconds` | `tool` | Tool execution time |

## Endpoints

- `GET /metrics` — Prometheus scrape endpoint
- `GET /errors` — Recent errors (last 100) in JSON format

## Logs

Structured JSON logs written to `logs/metrics.jsonl`:
```json
{"ts": "2026-07-20T10:30:00Z", "tool": "superset_create_chart", "status": "success", "duration_ms": 1240, "resource_type": "chart"}
```

## Dashboards

Three pre-built Grafana dashboards:

### 1. Usage Overview
- Tool calls rate over time
- Total tool calls
- Success rate
- Query execution rate by source
- Direct DB query rate by database type
- Error rate by tool

### 2. Resources Created
- Charts, datasets, dashboards creation rate
- DBAnalysis charts generated by type
- Dashboard layouts generated by type
- Transfer success rate
- Transfer items by type (pie chart)
- Transfer items rate

### 3. Performance & Errors
- Average and P99 tool latency
- API request rate by endpoint
- API errors (4xx/5xx) by status code
- Error rate by tool
- Error count by tool (top 10)
- Error details (from in-memory buffer)
- Transfer failure rate by item type
- HTTP status code distribution

## Docker

Add these services to `docker-compose.yml`:

```yaml
grafana:
  image: grafana/grafana:10.4.0
  ports: ["3000:3000"]
  environment:
    - GF_SECURITY_ADMIN_PASSWORD=admin
  volumes:
    - grafana_data:/var/lib/grafana
    - ./monitoring/grafana/provisioning:/etc/grafana/provisioning
  depends_on:
    - prometheus

prometheus:
  image: prom/prometheus:v2.51.0
  ports: ["9090:9090"]
  volumes:
    - ./monitoring/prometheus/prometheus.yml:/etc/prometheus/prometheus.yml
    - prometheus_data:/prometheus
  depends_on:
    - fast-mcp
```

## Adding New Metrics

```python
from modules.metrics import get_metrics

mc = get_metrics()
mc.tool_calls.labels(tool="my_tool", status="success").inc()
mc.tool_duration.labels(tool="my_tool").observe(1.23)
```
