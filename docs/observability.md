# Observability Layer

Structured metrics collection and Prometheus integration for AutomationMCPSuperset.

## Architecture

```
MCP Tools → MetricsCollector → JSON logs + Prometheus metrics
                                       ↓
                                  /metrics endpoint
                                       ↓
                                Prometheus (pull)
                                       ↓
                                  Grafana (3 dashboards)
```

## Metrics

### Counters

| Metric | Labels | Description |
|--------|--------|-------------|
| `tool_calls_total` | `tool`, `status` | All MCP tool executions |
| `resources_created_total` | `resource_type` | Datasets, charts, dashboards, virtual datasets |
| `transfers_total` | `status` | Dashboard transfers (success/failed/partial) |
| `transfers_items_total` | `status`, `item_type` | Per-item transfer stats |
| `queries_executed_total` | `source` | SQL Lab, data queries, chart data |
| `charts_generated_total` | `chart_type` | Bar, line, scatter, pie, explore |
| `dashboards_generated_total` | `layout_type` | Simple, robust, full dashboard |
| `api_requests_total` | `method`, `endpoint`, `status_code` | HTTP calls through api_client |
| `db_queries_total` | `db_type`, `status` | Direct DB queries (DBAnalysis) |

### Histograms

| Metric | Labels | Description |
|--------|--------|-------------|
| `tool_duration_seconds` | `tool` | Tool execution time |

## Endpoints

- `GET /metrics` — Prometheus scrape endpoint
- `GET /errors` — Recent errors (last 100) in JSON format

## Logs

Structured JSON logs written to `logs/metrics.jsonl`:
```json
{"ts": "2026-07-20T10:30:00Z", "tool": "superset_create_chart", "status": "success", "duration_ms": 1240, "resource_type": "chart"}
```

## Dashboards

Three pre-built Grafana dashboards under folder **"AutomationMCPSuperset"**:

### 1. Usage Overview
| Panel | Shows |
|-------|-------|
| Tool Calls Rate (per minute) | All tool executions over time, grouped by tool |
| Total Tool Calls | Cumulative count |
| Success Rate | `success / total` (green >95%, yellow >50%, red below) |
| Query Execution Rate (per minute) | SQL Lab / data queries over time |
| Direct DB Query Rate (per minute) | DBAnalysis queries by database type |
| Error Rate by Tool (per minute) | Red line — which tools are failing |

### 2. Resources Created
| Panel | Shows |
|-------|-------|
| Charts/Datasets/Dashboards Created | Creation rate per resource type |
| Charts Generated by Type | Bar chart: bar/line/scatter/pie from DBAnalysis |
| Dashboard Layouts by Type | Bar chart: simple vs robust |
| Transfer Success Rate | Gauge: % of successful transfers |
| Transferred Items by Type | Pie chart: datasets vs charts vs dashboards |
| Transfer Items Rate | Success vs failed transfers over time |

### 3. Performance & Errors
| Panel | Shows |
|-------|-------|
| Avg / P99 Tool Latency | Execution time per tool |
| API Request Rate (per minute) | Superset API calls by endpoint |
| API Errors (4xx/5xx) | HTTP error rate by status code (per minute) |
| Error Rate by Tool (per minute) | Which tools fail most often |
| Error Count by Tool | Table: top 10 tools with highest error counts |
| Error Details | Table: timestamp, tool, error message |
| Transfer Failure Rate (per minute) | Items that failed by type |
| HTTP Status Distribution (per minute) | Breakdown of 200/400/401/500 etc. |

## Docker

Add these services to `docker-compose.yml`:

```yaml
grafana:
  image: grafana/grafana:10.4.0
  ports: ["3000:3000"]
  environment:
    - GF_SECURITY_ADMIN_PASSWORD=admin
  volumes:
    - grafana_data:/var/lib/grafana
    - ./monitoring/grafana/provisioning:/etc/grafana/provisioning
  depends_on:
    - prometheus

prometheus:
  image: prom/prometheus:v2.51.0
  ports: ["9090:9090"]
  volumes:
    - ./monitoring/prometheus/prometheus.yml:/etc/prometheus/prometheus.yml
    - prometheus_data:/prometheus
  depends_on:
    - fast-mcp
```

## Adding New Metrics

```python
from modules.metrics import get_metrics

mc = get_metrics()
mc.tool_calls.labels(tool="my_tool", status="success").inc()
mc.tool_duration.labels(tool="my_tool").observe(1.23)
```
